# 事前登録 — 暴落後の指数エクスポージャ・タイミング（CRASH_INDEX_TIMING）

作成: 2026-08-02（**戦略リターンを見ていない時点で確定**）
ファミリー: `CRASH_DIPBUY` の第2仕様（新しい枠は増やさない）

## 0. なぜこれを試すのか

暴落ディップバイ（NO-GO）の分解で、**市場自体は1エピソードあたり +1.60% 反発しており、
銘柄選択がそれを −0.26% 削っていた**ことが判明した。
＝**反発は実在するが、それは市場全体に等しく来るもので、銘柄選択に情報が無い**。

ならば銘柄選択を捨て、**指数エクスポージャのタイミングだけ**を取る形が素直。
この構成は過去の壁を3つとも回避する:
- 借株制約 … ロングオンリーなので無関係（直近5例の死因）
- 税区分 … **現物ETFなので株式の枠内で完結**（先物ヘッジのような損益通算問題が無い）
- 銘柄選択 … そもそも行わない

## 1. 対象と執行

| 項目 | 値 |
|---|---|
| 銘柄 | **1306（TOPIX連動型上場投信）**。2018-2026で価格100%取得済み |
| 建玉 | 現物ロングのみ・レバなし・元本¥20M |
| トリガ | 等加重市場（¥10億ユニバース）の終値→終値 **≤ −3.0%** |
| エントリ | トリガ日の**翌営業日 寄成** |
| エグジット | エントリから **10営業日**後の**引成** |
| 重複 | 保有中に再トリガしたら**エグジットを後ろへ延長**（建玉は常に0か1。ナンピンしない） |
| コスト | 売買イベントごとに**往復20bps**（流動ETFに対し十分保守側） |

単元丸めは**評価対象外**（1306は1単元が元本の1%未満で、粒度の影響が無視できる。
実際の影響を `lot_impact` として報告するが判定には使わない）。

## 2. 判定（実測を見る前に確定）

比較対象は**同期間の1306バイ&ホールド**。次を**すべて**満たしたときだけ次段階へ:

1. 戦略の **Sharpe ≥ 1.0**（リポジトリ共通基準）
2. 戦略の Sharpe が **バイ&ホールドを上回る**
3. 戦略の **最大DD がバイ&ホールドより浅い**

副次（判定に使わない）: 年率、投資日数比率、年別内訳、1日あたり収益。

## 3. 感度分析（主仕様の昇格禁止）

トリガ −4% / −5%、保有 5 / 20営業日。**良かったセルを主仕様に昇格させない。**

## 4. 禁止事項

- 結果を見た後のトリガ・保有日数・銘柄（1306）・コストの変更
- 素のリターンだけでの主張（必ずバイ&ホールド比較を併記する）
- レバレッジや先物・信用の追加（税区分と借株の壁を再導入するため）
