# 事前登録 — 東京仲値・ゴトー日アノマリー（FX_GOTOBI）

作成: 2026-08-05（**リターンを一切見ていない時点で確定**）
ファミリー: `FX_BASKET` の第4弾（日中フロンティアの1本目）

## 0. 仮説

日本の輸入企業のドル決済は**ゴトー日（5・10日）の東京仲値（9:55 JST）**に集中し、
銀行はカバーのため仲値前にドルを買う。この実需フローが USDJPY を**9時台に押し上げる**
（Ito–Yamada が学術的に記録した歪み。2017年の仲値改革後に減衰した可能性も既知）。

日次〜週次のFXが8仮説全滅した後の、**日中に残された数少ない構造的な歪み**。

## 1. データ

Dukascopy 時間足 bid/ask（USDJPY・2011-01〜2026-07・136,584本・仲値バー欠損0%）。
JSTは夏時間が無いので **00:00 UTC バー = 09:00–10:00 JST が常に仲値(9:55)を含む**。

日本の銀行営業日は**TSE営業日**（手元の株式パネル）で代理する
（銀行休業日≈TSE休場日。完全一致ではないことを明記）。

## 2. 仕様（確定）

- **ゴトー日**: 暦日の 5・10・15・20・25・30 日。その日が営業日でなければ
  **直前の営業日へ前倒し**（仲値決済の実務慣行）。同一日に複数が畳まれたら1回と数える
- **トレード**: ゴトー日に **00:00 UTC バーの始値(ask)で USDJPY を買い、
  同バーの終値(bid)で売る**（= 09:00 JST 買い → 10:00 JST 売り。仲値9:55を跨ぐ）
- 1日1トレード・サイズ1・オーバーナイトなし（スワップ無関係。ロールオーバー7:00 JSTも跨がない）
- コストは bid/ask 実測値に内包（ask買い・bid売り）

## 3. 対照（診断・判定には使わない）

- **非ゴトー営業日**に同じ 09:00→10:00 トレード（「ただの東京朝ドリフト」との分離）
- 曜日別・年別の分解

## 4. 窓と判定（確定）

- 選択窓 **2011-2019** / 確認窓 **2020-2026**（このシグナルでは両窓とも未消費）
- 基準（**両窓それぞれ**で全て）:
  ① 全暦日 net Sharpe ≥ 1.0　② 負の年 ≤ 全年数の1/3
  ③ 上位5トレードの利益シェア < 20%　④ 上位10トレード除去後 Sharpe ≥ 0.5
- 補助判定（真正性）: **ゴトー日の平均 > 非ゴトー日の平均**が両窓で成立すること
  （成立しない場合、それはゴトー日アノマリーではなく時間帯効果）

## 5. 感度分析（昇格禁止）

保有を 23:00 UTC 始値→01:00 UTC 終値（8:00→10:00 JST）、ゴトー日を 5・10 のみ／25・30 のみ、
売り側（10:00→11:00 JST の反落仮説）。

## 6. 禁止事項

- 結果後の時間窓・ゴトー日定義・前倒し規則の変更
- 感度セル（特に反落側）の主仕様への昇格
- 分足での精査を「分足で改善したから採用」に使うこと（分足は形の確認のみ）
