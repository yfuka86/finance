# 事前登録 — FX セッション効果（自国営業時間の自国通貨減価・Ranaldo型）

作成: 2026-08-08（**リターン計算前に確定**）
ファミリー: `FX_BASKET`（セッション効果は新セル）

## 0. 仮説と根拠

Ranaldo (2009) の定型事実: **通貨は自国市場の営業時間中に減価する**（輸入実需・機関の
ヘッジフローが自国通貨売りに偏るため）。我々自身の実測でも東京仲値フロー
（ゴトー日 9:00→9:55 グロス+2.13bps・対照日も正）が**このJPYインスタンスの生存**を示す。
既存の時間帯セズナリティWFの棄却は「(ペア,時刻)セルの毎年再選択」であって、
**理論固定のセッション保有はまだ検証していない**。毎日・複数レッグ＝高頻度要件を満たす。

## 1. 凍結仕様（レッグと方向・変更禁止）

各レッグ「自国通貨の営業時間に、その通貨を売る」。すべて当日内・NYロールオーバー非跨ぎ:

| レッグ | 取引 | 窓（現地時間・DST処理） |
|---|---|---|
| JPY | USD_JPY ロング | 09:00→15:00 Asia/Tokyo |
| EUR | EUR_USD ショート | 08:00→16:00 Europe/Berlin |
| GBP | GBP_USD ショート | 08:00→16:00 Europe/London |
| AUD | AUD_USD ショート | 09:00→17:00 Australia/Sydney |
| NZD | NZD_USD ショート | 09:00→17:00 Pacific/Auckland |
| CHF | USD_CHF ロング | 08:00→16:00 Europe/Zurich |
| USD | EUR_USD ロング | 11:00→16:30 America/New_York（ロンドン閉場後のUS単独時間） |

- CADレッグは**除外**（トロント営業時間がUSD自国時間と重なり方向が定義できない）
- ポートフォリオ: 等ウェイト（各レッグ notional 1/7）・毎営業日
- 約定: 窓開始/終了の直近分足mid±実測ハーフスプレッド（開始+30分/終了−30分以内に
  バーが無い日はそのレッグ休み）。スワップなし（全レッグ17:00 ET非跨ぎ）

## 2. コスト（事前固定）

主判定 = **OANDA実測ハーフスプレッド**（約定バー・p99 winsorize）。
感度 = GMO相当（USDJPY 0.2銭固定・他ペアは実測の0.6倍）。

## 3. 窓と判定（実測を見る前に確定）

- 選択窓 **2011-2019** / 確認窓 **2020-2026**（全基準通過時のみ1回開封）
- 基準（ポートフォリオ・両窓）: ①全暦日 net Sharpe ≥ 1.0 ②負の年 ≤ 1/3
  ③上位5日利益シェア < 20% ④上位10日除去後 Sharpe ≥ 0.5
- 感度（事前列挙）: a) 各レッグ窓の前半3時間のみ（自国午前に集中する既知パターン）
  b) GMOコスト
- レッグ別のグロス/ネットは**診断として記録**するが、**特定レッグの事後昇格は禁止**
  （やるなら新しい未使用期間で別事前登録）

## 4. 開示

- JPYレッグはゴトー封印（USDJPY 9:00→9:55・ゴトー日・2020+）と時間帯が部分重複する。
  本検証の確認窓開封はゴトー封印の開封を意味しない（戦略定義が異なる）が、
  重複の存在をここに開示する。選択窓の設計にゴトー実測（消費済み選択窓の観測）を
  用いたことも開示する（確認窓は未接触のまま）。

## 5. 禁止事項

結果後の窓時刻・レッグ集合・方向の変更。感度セルの主仕様昇格。レッグ単体の事後選抜。
