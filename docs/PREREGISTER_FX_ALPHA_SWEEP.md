# 事前登録 — FX 独立4因子スイープ（FX_ALPHA_SWEEP）

作成: 2026-08-04（**戦略リターンを一切見ていない時点で確定**）
ファミリー: `FX_BASKET` の第3弾

## 0. 位置づけ

検証済みで死んだもの: クロスセクション・キャリー(0.14/0.07)、12週モメンタム(0.55/0.23・
集中で崩壊)、正キャリーのディップバイ(−0.21)、バイ&ホールド(最良USDJPYロング0.53)。

本試行は**未検証の独立4因子**。キャリー水準・価格モメンタムの変種ではない。
**4本同時に試すことの多重性**は認識している: だからこそ判定は
「選択窓と確認窓の**両方**で全基準を満たす」ことを要求し、片窓のみの合格は不合格とする。

各シグナルの確認窓(2020+)のリターンは**まだ一度も計算していない**ので、
これらのシグナルにとって確認窓は未消費である。

## 1. データ

- 価格・スプレッド: Dukascopy 日足 bid/ask（7 USDペア・2011-2025・実測スプレッド）
- 長期シグナル履歴: **ECB 仲値**（1999〜。14:15 CET 固定＝当日中に既知でPIT安全。
  シグナル構成のみに使い、損益は常に Dukascopy で計算）
- 金利: FRED 3か月インターバンク（月次）。**シグナル用途は1か月ラグ**（公表遅延の保守側）。
  スワップの経済的発生は現行値の前方補完（これはシグナルではなく発生額）
- スワップ: `trading/fx/swap.py`（水曜3日・週合計7日）

## 2. 共通の建て方（確定）

毎週**金曜**リバランス、8通貨の対数強弱（USD基準）バスケット、
上位2ロング/下位2ショート（±1）、コストは**実測ハーフスプレッド×建玉変化**、スワップ加算。
Sharpe は**全暦日ベース**。

## 3. 4仮説（確定）

| # | 名 | シグナル（すべて t−1 までの情報） | 根拠 |
|---|---|---|---|
| A | **ドル・タイミング** | `r_USD − mean(r_他7通貨)`（1か月ラグ金利）の符号で USD バスケットをロング/ショート（±1、他通貨∓1/7） | Lustig-Roussanov-Verdelhan のドルキャリー。クロスセクションでなく**ドル自体のタイミング** |
| B | **長期リバーサル** | ECB由来の対数強弱の **5年移動平均からの乖離**。乖離が最も負の2通貨ロング/最も正の2ショート | PPPバリューの名目代理（JPYのCPIが2021-06で入手不能のため。低インフレ主要国では5年名目≈実質。**この置換により純粋なPPP検定ではない**ことを明記） |
| C | **金利モメンタム** | 3か月前比の金利**変化**（1か月ラグ）。上昇上位2ロング/低下上位2ショート | 金融政策の方向。キャリー（水準）とは別物 |
| D | **週次リバーサル** | 直近5営業日のバスケット・リターン。下位2ロング/上位2ショート | 短期の流動性供給。12週モメンタムの逆符号・別ホライズン |

## 4. 窓と判定（確定）

- 選択窓 **2011-2019** / 確認窓 **2020-2025**
- **選択窓で全基準を満たした仮説のみ、確認窓を1回だけ開く**（落ちた仮説の確認窓は温存）
- 基準（両窓それぞれ）: ①net Sharpe ≥ 1.0（全暦日） ②負の年 ≤ 全年数の1/3
  ③上位5週の利益シェア < 20% ④上位10週除去後 Sharpe ≥ 0.5

## 5. 感度分析（合格仮説のみ・昇格禁止）

上位/下位1・3通貨、リバランス隔週、`haircut_bp` ∈ {25,50}。

## 6. 禁止事項

- 結果を見た後のシグナル定義・ラグ・通貨数・窓の変更
- 落ちた仮説の閾値替え再試行（その時点で選択窓は消費済み）
- 4本のうち良かったものだけを取り出して「発見」と称すること
  （4本試したという多重性を必ず併記する）
- B を「PPPバリューの検証」と読むこと（名目代理である）
