# 事前登録: バリュー株の価値解放イベント

登録日: 2026-08-01。`CORPORATE_EVENTS` ファミリーの主戦略であり、研究枠を追加しない。

## 仮説

低PBR・低EV倍率そのものではなく、割安で財務余力のある企業に、余剰資本・非中核資産・支配構造を
変える観測可能なイベントが発生したときだけ、中期的な価値解放が起きる。

## イベント前に固定するvalue state

- PBR、earnings yield、FCF yield、net cash / market cap、ROE、営業利益率。
- 業種内rankを使い、赤字・継続企業疑義・極端な低流動性は除外する。
- イベント開示後の価格・財務値で「イベント前の割安度」を書き換えない。

## 対象イベント

1. `capital_release`: 市場買付型自社株買いの実行加速、自己株消却、増配、政策保有株縮減。
2. `control_change`: 大量保有目的の重要提案行為への変更、連続買増し、TOB/MBO/完全子会社化。
3. `asset_release`: 非中核事業・不動産・持合株の売却、事業撤退、会社分割等の再編。

決算サプライズや単なる「資本コストを意識した経営」開示は対象外。PEADと定型文反応の再検証を避ける。

## PITと売買

- `first_received_at`後の最初の取引可能時点からのみ評価。イベント前value stateを結合する。
- 主仕様はlong-only、レバレッジなし、1案件NAV 3%上限、同時10案件上限、20～120日状態保有。
- 終了はイベント完了・取消・条件悪化・120日。結果を見て20/40/60/120日の最良を選ばない。
- 売買コスト、寄付きギャップ、上場廃止、TOB応募・資金拘束を案件別に計上する。
- 対照は開示前に固定した同業種・時価総額・β・value state近傍。対照ショートは実売買せず、
  abnormal return計測だけに使う。戦略自体は株式long-onlyで完結する。

## 判定

- 低頻度イベントなので日次Sharpeだけで選ばない。案件平均・中央値、案件クラスタbootstrap、
  最大損失、expected shortfall、資金拘束、上位1/5案件の利益集中を主評価にする。
- GO候補: コスト後案件中央値>0、クラスタ95%CI下限>0、最大DD>-20%、上位1案件寄与<20%、
  各calendar yearで案件合計>0。いずれか未達でNO-GO。
- 対象イベントを結果後に削る、value閾値を動かす、保有期間を最適化することは禁止。
- 現在はイベント履歴未取得のため `DATA BLOCKED`。PnLを作らず、先にPIT完全性を検証する。

## サブモデルV1: 増配×低PBR（2026-08-01、結果確認前に固定）

正式な自社株買い履歴を待つ間も検証可能な `capital_release` の独立サブモデルとして、
J-Quants財務開示の予想年間配当を使う。これは `buyback_pressure` の代替データではない。

- イベント: 同一 `CurFYEn` 内で `FDivAnn` が直前開示比20%以上増加。ゼロ・欠損からの変化は除外。
- value gate: 開示前終値で `0 < PBR <= 1`、EPS>0、営業利益>0、前日売買代金>=10億円。
- 特徴量: 増配率、B/P、E/P、営業利益率、自己資本比率、cash/assets、ROEの7本だけ。
- モデル: StandardScaler + median補完 + Ridge(alpha=10)。2021-2023年の完了案件だけで1回学習。
- 確認期間: 2024-01-01以降。予測値>0の案件を時系列順に採用し、同時10件まで。
- 執行: 開示後の翌取引セッション寄付きで買い、60取引セッション後の引けで売却。
  1案件NAV 3%、レバレッジなし、往復20bps。結果を見て期間・閾値・alphaを変更しない。
- 判定は上記共通基準。確認期間を見た後の変更はV2とし、新しい未使用期間が必要。

## V1データ適格性テスト結果（2026-08-01）

`scripts/run_value_event_v1.py` を実行。増配イベントは1,637件検出したが、PBR計算に必要な
当時基準の未調整終値が手元の日足では2022～2024年に全欠損していた。調整済み終値と当時BPSを
混ぜると、後日の株式分割により偽の低PBR・偽の外れ値利益が発生することを実測で確認した。

そのため未調整終値を必須化し、欠損を推測しない実装へ修正。適格案件2件、学習完了案件0件となり、
結果は **DATA_BLOCKED**。OOS成績は有効に観測しておらず、GO/NO-GO判定も未実施。
再開条件は、イベント開示日の直前営業日における未調整終値を正本の日足へ補完すること。

データ保全方針: 元データ、派生データ、失敗・無効判定を含む実行結果は削除しない。実行結果は
`results/value_event_v1/` に時刻と内容hash付きでappend-only保存する。誤った価格基準による
初回試算も `INVALID_AUDIT_ONLY` と明記して監査記録として保持する。

J-Quantsから価格非依存の固定条件を満たす160銘柄について2021～2026年の未調整O/Cを取得し、
既存の年次正本Parquetの欠損セルだけを補完した。重複価格ファイルは作成していない。

- 適格案件51件、学習完了案件21件、OOS候補23件、採用17件。
- 往復20bps後: 案件平均+6.28%、中央値+4.84%、勝率64.7%、最大損失-25.80%。
- 利益合計+106.74%（案件リターン単純合計）、最大利益案件の利益寄与64.69%。
- 事前登録した利益集中上限20%を超えたため、**V1はNO-GO**。

OOS結果を見た後の閾値・保有期間・ridge alpha変更は行わない。V1の再選択は禁止する。
