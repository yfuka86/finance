## V2B 自己株消却代理

連続する財務開示間で、以下をすべて満たすイベント。

- 発行済株式数が0.5%以上減少。
- 自己株式数の減少が直前発行済株式数の0.5%以上。
- `(発行済株式数－自己株式数)` の変化が直前値の±0.25%以内。

株式分割、自己株処分、増資を機械的に避け、発行済みと自己株がほぼ同数減る消却だけを代理捕捉する。
