# 事前登録: 動的入替・オーバーナイト階層LASSO

登録日: 2026-07-31。既存の単純overnight/cc1反転とは別に、保有中も毎日情報を更新し、
強い銘柄だけを残す低回転L/Sを検証する。

## 固定仕様

- D日引け後に計算し、D+1引成で新規・入替。D+1引けからD+2引けのclose-to-closeを取る。
  D日終値をD日引け注文へ使うlook-aheadは禁止。
- TOPIX500相当、前日売買代金10億円以上、¥20M、gross 2.0、100株単元。
- 特徴量・階層残差化・LASSOの年次WFとalpha選択は
  `PREREGISTER_topix500_hierarchical_lasso.md` と同一。
- 目的変数はD+1引け→D+2引けの33業種内残差リターン。
- 入替ルール: 新規候補は予測rank上位/下位10%、既存建玉は上位/下位20%内なら維持。
  最大40銘柄/側。ショートは各入替日のPIT貸借かつ規制なしのみ。
- 目標は予測強度比例、各サイド¥20M以内で100株単元化。売建不能になった既存ショートは返済。
- コスト: 引け板寄せの実ウェイト変化に0.5bps。ショート残高に年4.2%を日割り課金。
- 日次のターンオーバー、銘柄数、L/S金額、ネット偏りを保存する。

## 判定

- 2024-01-01以降を一度だけ集計。
- GO: net Sharpe>=1.0、各年net年率>0、DD>-20%、平均片道turnover<20%/日、
  上位10銘柄の絶対寄与<30%。一つでも未達ならNO-GO。
- 結果後の閾値・保有銘柄数・金利・alpha変更は禁止。

証券会社固有の過去在庫は取得不能。バックテストの貸借＋規制判定を通っても、ライブでは
毎日APIの売建可能数量を確認し、在庫なしなら新規ショートを見送る。
