# 事前登録: 中期・個別残差 ML ロングショート

登録日: 2026-07-31。よしそ氏の公開発言にある「個別リスク中心の大規模 L/S」を、
既存の寄引・単純モメンタム実験と異なる仮説として一度だけ検証する。

## 固定する仮説と構成

- 意思決定: 日次引け後。翌営業日の寄付きで建てる（当日終値までの情報のみ）。
- 保有: 10営業日。5営業日ごとに新しいトランシェを建てる2トランシェ方式。
- モデル: expanding annual walk-forward Ridge (`alpha=30`)。
- 学習目的: 翌営業日寄付きから10営業日目引けまでの個別株リターンを、同日の33業種平均から
  引いた残差。テスト年より前の年だけで学習する。
- 特徴量:
  - 価格・リスク: 前日までの1/5/20/60日リターン、20日ボラ、60日β、Amihud、時価総額。
  - PIT財務: earnings yield、book-to-price、営業利益率、ROE、自己資本比率、営業CF/純利益、
    売上・営業利益予想の開示間変化。開示日の翌営業日から使用する。
  - PIT需給: `FLOW_FEATURES` と `EXTRA_FEATURES`（既存の保守的公表ラグをそのまま使用）。
- 欠損: 中核価格特徴量が欠ける行は除外。財務・需給は学習期間の中央値で補完し、欠損フラグを付ける。
- ユニバース: 個別株、前日売買代金10億円以上。ショートはPIT貸借銘柄かつ規制なし。
- 構築: 33業種ごとに予測上位20%をロング、ショート可能銘柄の下位20%をショート。
  各サイド0.5、全体gross 1.0。各トランシェはgross 0.5。
- コスト: 実際のウェイト変化 `sum(abs(w_t-w_{t-1}))` に1bpsを乗じる。
  建て＋手仕舞いの完全入替なら2bps/日ではなく、各トランシェの往復で2bpsとなる。
- 金利: ショート残高に年4.2%を日割り課金（一般信用を楽観しない）。

## 判定

- 主期間: 2024-01-01以降の年次ウォークフォワード予測。
- GO: net Sharpe >= 1.0、各暦年のnetリターンがすべて正、最大DD > -20%。
- いずれか未達ならNO-GO。結果確認後の特徴量・alpha・保有期間・分位変更は禁止。

注意: 2024年以降はリポジトリ内の別実験で観測済みであり、完全な未使用期間ではない。
したがって合格しても本番採用せず、構成を凍結して新しいフォワード期間で再確認する。

## 実行可能性の追補（初回結果確認後・ユーザー指示によるため別仕様）

初回の分数ウェイト評価後、ユーザーから「実際に取引でき、売りは常に可能とは限らない」
という要件が追加された。さらにUKI氏の記事に合わせ、以下を追加する。この結果は上の事前登録と
同一の未見テストではなく、**実行可能性を優先した別仕様の診断**として扱う。

- TOPIX500相当（Core30/Large70/Mid400）のみ。
- 元本2000万円、100株単元。各トランシェ・各サイドの予算内で整数ロット化。
- ショートは意思決定日だけでなく、翌営業日にもPIT貸借かつ規制なしの銘柄だけ。
- 翌朝の証券会社APIによる一般信用在庫確認はライブ必須。過去在庫履歴は存在しないため、
  バックテストでは制度信用貸借＋規制履歴が再現可能な上限である。
