# 事前登録 — ファンダ×フローの保有期間フロンティア（時間軸自由化・ユーザー指示 2026-08-11）

作成: 2026-08-11（**リターン計算前に確定**）。ファミリー: `QUOTEFREE`

## 0. 問い

「フロー×ファンダのαはどの時間軸に住んでいるか」。既知: フローαは日中専用（夜間は逆符号）・
ファンダは60営業日イベント（V4）で実在・中期MLの過去NO-GOは**財務が実はNaNだった**ため
帰属不明。**正しくマージされたPIT財務の断面αを保有期間の関数として初めて測る**。

## 1. 執行形（凍結・全て引け板寄せ）

- D引け後計算 → **D+1引成で建て → D+1+h引成で返済**（1日遅延・B案/dynamic-ccと同じ実行可能形）
- **hトランシェ重畳**: 毎営業日1トランシェを入替（定常回転 ≤ 2/h /日・実測回転で課金）
- 収穫: `ret_cc_fwd`（隣接セッションガード済み）の連鎖
- 構築: セクター内z上位/下位**10%**の等ウェイトL/S（¥10億フロア・ショートは貸借∧非規制のみ）
- コスト: 板寄せ0.5bps/side×**実測日次回転**＋ショートnotionalに4.2%年率/245日（ロングは現物想定）

## 3. 窓と判定（実測を見る前に確定）

- 選択窓 **2018-2024** / 確認窓 **2025-01+**（v1日中MLで部分消費済み＝汚染を明記の上、
  通過セルのみ1回開封）
- 基準（分数ウェイト段階）: ①全暦日 net Sharpe ≥ 1.0 ②負の年 ≤ 1/3 ③上位5日 < 20%
  ④top10除去後 ≥ 0.5 ⑤グロス ≥ 全込みコスト×2
- **通過セルは条件数最小→hの短い順に1つ凍結**し、さらに**¥20M単元バックテスト**（8銘柄/側
  相当の集中形 magnitude）で net Sh ≥ 1.0 を要求（分数→単元の落差検査）。両方通過時のみ確認窓へ
- 全滅なら: 「正しい財務でも断面αは保有期間に依らず不在」を確定し、ファンダ系は
  イベント駆動（V4フォワード）のみを残して閉じる
