# 事前登録 — FX時間帯セズナリティ・ウォークフォワード（FX_HOURLY_SEASONALITY）

作成: 2026-08-06（**戦略リターンを計算する前に確定**）
ファミリー: `FX_BASKET` の第6弾・**高頻度主軸**（ユーザー指示: 低頻度戦略の優先度を落とす）

## 0. 仮説

FXの時間帯リターンには機関フローの定時性による持続的な偏りがある
（Breedon–Ranaldo: 通貨は自国市場の時間帯に減価する、等）。
単一の時間帯を事後に選ぶと過学習になるため、**選択規則そのものを凍結し、
ウォークフォワードで毎年選び直す**。全リターンがOOSになる。

## 1. データとコスト

- Dukascopy時間足 bid/ask（USDJPY・EURUSD、2011-2026、手元に完備）
- コスト: **GMO原則固定**（USD/JPY 0.2銭・EUR/USD 0.3pips）を**セルごとに毎回全額課金**
  （連続セルの結合による節約はしない＝保守側）
- **取引可能時間はGMO原則固定の対象内のみ**: 9:00〜翌3:00 JST = **UTC 0〜17時**の18時間。
  UTC 18-23時（JST 3-9時）は対象外なのでセルに含めない

## 2. セルと選択規則（凍結）

- セル = （ペア2）×（UTC時 0..17）×（方向 ±1）= **72セル**
- **ウォークフォワード**: 各年 Y（2014..2026）について、**2011年からY-1年末までの拡大窓**で
  セルごとの平均ネットリターンと t 値を計算し、
  **t ≥ 2.5 かつ ネット平均 > 0** のセルを **t 降順に最大6個**選び、Y年の毎営業日それを執行する
- 選ばれない年はそのセルを建てない（0セルの年は全休）

## 3. 判定（凍結）

ウォークフォワード列（2014-2026・全リターンがOOS）に対し:

1. 全暦日 net Sharpe ≥ 1.0
2. 負の年 ≤ 全年数の1/3
3. 上位5日の利益シェア < 20%
4. 上位10日除去後 Sharpe ≥ 0.5
5. 前半2014-2019と後半2020-2026の**両方**で Sharpe ≥ 0.5（半期安定性）

## 4. 診断（判定に使わない）

年ごとの選択セル一覧（安定性）、セル数の推移、ペア別寄与、
Dukascopy実測スプレッドでのシナリオ。

## 5. 禁止事項

- 結果を見た後の t 閾値・セル上限・対象時間・ペア集合の変更
- 特定年の選択セルを手で差し替えること
- 「もし閾値がXなら」の事後探索（感度分析は t∈{2.0, 3.0}・上限{3,10}の4セルのみ、昇格禁止）
