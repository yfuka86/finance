# 事前登録 — バリュー株イベント V4: 母集団の流動性再定義（増配×低PBR）

作成: 2026-08-08（**リターンを一切見ていない時点で確定**）
ファミリー: `CORPORATE_EVENTS`

## 0. なぜ V4 が成立するか（V1-V3 の確定知見への回答）

V1(増配)・V2(復配/消却)・V3(固定株縮減)は全て NO-GO。ただし AGENTS の確定知見は
「**この枠の問題は閾値でなく標本供給**。次に続けるなら別イベントではなく
**流動性制約と両立する母集団の再定義**が必要」。本書はその再定義そのもの。

- 死因の実測: PBR≤1 と ¥10億フロアが**ほぼ排他**（増配でも全期間51件・OOS23件しか残らない）
- **¥10億は日中戦略から継承した値**で、60営業日保有には根拠がない。実務検算:
  1案件¥200万・3日分割エントリで、フロア¥1億でも**参加率0.7%**（板寄せの許容内）
- フロア¥1億なら適格 **262件・OOS24+ 125件（5倍）**＝集中基準を満たしうる標本量

**変更点はこの1つだけ**（フロア ¥10億→¥1億）。シグナル・モデル・特徴量・保有・選択規則は
V1 の凍結仕様を一切変更しない。

## 1. 仕様（V1と同一・再掲）

- イベント: 同一期内の予想配当を**+20%以上**増配（PIT・DiscDate順）
- 適格: PBR∈(0,1]（未調整終値×当時BPS）・EPS>0・OP>0・**前日売買代金≥¥1億**←唯一の変更
- エントリ: 開示翌営業日の寄成 / エグジット: 60営業日後の引け / 同時最大10案件
- モデル: Ridge(α=10)+impute+standardize・FEATURES 7本・学習 exit<2024-01-01・OOS event≥2024-01-01

## 2. コスト（事前固定）

主判定 **往復40bps**（小型株の板寄せスプレッドを保守的に見る。V1の20bpsは比較用に併記）。

## 3. 判定（実測を見る前に確定）

1. OOS採用案件 **≥ 30**
2. **40bps後の案件中央値 > 0**
3. **最大利益案件の利益シェア < 20%**
4. **増分母集団（¥1億〜10億のみ・V1で未評価の新規イベント）単独でも中央値 > 0**
   （V1が消費した¥10億超23件に結果が依存していないことの確認）

## 4. 窓の開示

OOS 2024+ のうち¥10億超の23件は V1 判定で消費済み。ただし母集団の**8割超（102件）は
一度も評価されていない新規イベント**であり、基準④が消費済み部分への依存を排除する。

## 5. 禁止事項

- 結果後のフロア・コスト・シグナル・保有期間の変更
- 基準④の増分評価を「別戦略」として二重計上すること
- 落ちた場合の V5（三度目の母集団変更）。この再定義が最後の一手
