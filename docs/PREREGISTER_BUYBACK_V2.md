# 事前登録: BUYBACK_PRESSURE v2

登録日: 2026-08-01。損益を確認する前に固定した。既存の `steady execution` の結果を使った
閾値調整ではなく、観測された実買付と需要消失という別の経済機構を対象にする。
同時に走らせる主仮説は2本までとし、追加案はデータ要件が満たされるまで保留する。

## A. Realized execution persistence（ロング、主研究）

認可上限ではなく、実際の市場買付が翌月も継続する仮説。

- `month_shares / purchase_month_sessions / ADV20 >= 5%`
- 同一プログラムの直前報告でも同指標が1%以上
- `purchase_day_ratio >= 50%`
- `max_daily_concentration <= 25%`
- `remaining_pressure >= 5%`、`remaining_sessions >= 10`
- ToSTNeT取得を除外
- 前日売買代金10億円以上、100株の寄付金額60万円以下
- 開示受信後の翌営業日寄付きでロング
- 20営業日、または完了・取消・`remaining_pressure < 2%` で退出
- 1案件NAV 3%、最大10案件、同一銘柄の重複保有なし
- 往復20bps。40bpsでも総収益が正であること

非損益診断では118報告・67プログラム、2026年3月以降24報告。最低20独立案件が確定するまで
採用判定を行わない。同一プログラムの月次重複は独立案件として数えない。

一回限りの過去確認は、エントリー日2026-01-01以降、同一プログラムの最初の適格報告だけを
独立案件として採用する。損益確認前にこの期間、重複処理、20bps/40bps同時評価を固定した。

### 凍結後の一回限り評価

初回計算では33案件・20bps後Sharpe 2.37となったが、結果後の敵対的監査で
`purchase_month_sessions` が月全体ではなく最初から最後の買付日までを数える不備を発見した。
圧力と買付日比率を過大評価し候補選択を変えるため、結果は **INVALIDATED / 利用禁止**。
同じ期間を修正後に再計算してOOSとは呼ばず、新しい未使用フォワード期間から評価を再開する。
監査記録は `results/buyback_persistence_oos_20260801.INVALIDATED.md`。

### Forward v3 品質ゲート

初回結果の無効化後、損益を再閲覧せず以下を追加した。月の分母はEDINETの`report_date`が属する
暦月の全取引所営業日とする。日次取得明細の株数合計が月次株数の99.5～100.5%、金額合計が
月次金額の99～101%に一致する報告だけを使用する。銘柄コード末尾が0の普通株だけを4桁へ正規化し、
末尾9等の別証券を同一銘柄へ統合しない。2026-08-03以降を新しいappend-onlyフォワード期間とし、
評価可能日は2027-08-03以降。旧期間の修正後成績は計算・表示しない。

フォワード生成v3.1は実行日より未来のas-ofを拒否する。`PERSISTENCE_LONG` は推定ADV金額10億円以上、
100株単元60万円以下を満たす場合だけ出力する。2026-08-01に先行生成した8月3日スナップショットは
開示欠落の可能性があるためINVALIDATED previewとして取引・評価から除外した。

候補の期限経過監査でv3.1にも古い報告が残る問題を発見したため、損益・取引前に無効化した。
v3.2では報告から45日以内、期間終了まで14暦日以上を追加し、期限切れ・報告停止プログラムを除外する。

## B. Completion cliff（ショート、またはロング退出）

大きな市場買付が終わった後、限界買い手の消失により相対的に下落する仮説。

- 同一プログラムで取得率が初めて95%以上に到達
- 直前報告の `remaining_pressure >= 10%`
- EDINET/TDnetの受信後、翌営業日寄付きから20営業日
- ショートは当時の貸借区分、売建規制なし、当日の証券会社在庫ありの場合だけ
- 100株単元、1案件NAV 3%、最大10案件、注文量はADV20の1%以下
- 往復20bpsに貸株料を追加。40bpsでも確認
- 売れない銘柄は発注せず、既存ロングの退出シグナルとしてのみ利用

感度分析は95%を100%へ変更する1本だけ。予定終了日前の先回り売りは、実際の需要消失をPITで
確定できないため採用しない。

非損益診断では構造上22プログラム、PIT貸借・規制・単元条件後11件、2026年3月以降3件。
流動性条件を加えた直近案件はゼロのため、現時点では `DATA-BLOCKED / FORWARD ONLY` とする。

## 保留する仮説

- 未実行・実行急減のショート: 月次取得ゼロかつ残存圧力10%以上は58報告・40プログラム。
  休止理由の本文分類とPIT売建在庫が未実装なので、実装まで観測専用。
- 低PBR×実買付ロング: 当時利用可能だったPBR・利益とPIT結合できるまで開始しない。
- 発表直後、取消、期限延長、消却、ToSTNeT単体: TDnetの受信時刻付き原文が揃うまで開始しない。

後日のEDINET報告から判明した取締役会日へ遡って売買することは禁止する。

## 共通Kill条件

- 12か月で独立かつ実発注可能な案件が20件未満
- 20bps後Sharpe 1未満、または40bps後総収益が非正
- 最大DDが-10%以下
- 最大利益案件の寄与が20%以上
- completion cliffの利益が非貸借・在庫なし銘柄へ集中
- ショートの在庫消失・強制返済率が10%超

結果を見た後の閾値変更、A/Bの成績による事後選択、同じ確認期間での再検証は禁止する。
