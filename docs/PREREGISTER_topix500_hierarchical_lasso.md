# 事前登録: TOPIX500 階層残差 LASSO（日中L/S）

登録日: 2026-07-31。UKI氏が公開した構成（TOPIX500、財務＋市況＋個別騰落、LASSO、
特徴量間の線形回帰・残差化、日中のみ）から、非公開部分を推測せず再現可能な仕様へ落とす。

## 固定仕様

- 意思決定: D日引け後。D+1寄成で建て、D+1引成で全て返済。
- 情報: D日引けまでの価格、D日までに利用可能なPIT財務・需給のみ。当日寄値・気配は不使用。
- ユニバース: TOPIX500相当（Core30/Large70/Mid400）、前日売買代金10億円以上。
- 特徴量: `experiment_medium_residual_ml.py` と同じ価格8・PIT財務8・PIT需給13。
- 階層前処理:
  1. 日次クロスセクションrank。
  2. 33業種平均を控除。
  3. 各特徴量を同日クロスセクションのβ・log時価総額へOLSし、その残差を入力。
- 目的変数: D+1の寄引リターンからD+1の33業種平均を控除した個別残差。
- モデル: expanding annual walk-forward LASSO。各テスト年YについてY-1年をvalidation、
  それ以前をfitに使用。alphaは `{1e-6,3e-6,1e-5,3e-5,1e-4,3e-4}` からvalidation MSEのみで選択。
  売買成績でalphaを選ばない。
- 構築: 予測値上位/下位から最大80銘柄/側。元本2000万円・gross 2.0、100株整数ロット。
  各サイド2000万円を予測強度比例で配分し、D日終値で100株単元数を決め、余剰を強い順に
  1単元ずつ配る（未知のD+1寄値をサイジングに使わない）。
- ショート: D+1時点のPIT貸借かつ規制なしのみ。証券会社固有在庫はライブAPIで再確認必須。
- コスト: 寄成1.5bps＋引成0.5bps＝売買元本に対して2bps/日。一日信用金利は0。

## 判定

- 2024-01-01以降を一度だけ集計。
- GO: net Sharpe >= 1.0、各年net年率>0、最大DD>-20%、上位10銘柄の絶対寄与<30%。
- 一つでも未達ならNO-GO。結果を見た後の特徴量、alpha grid、銘柄数、レバ変更は禁止。

2024年以降は他実験で観測済みのため完全な未使用期間ではない。合格しても候補凍結までとし、
本番採用には新規フォワード期間が必要。
