# 事前登録 — 大量保有報告書・新規5%超イベント（機関投資家のあしあと・銘柄レベル)

作成: 2026-08-08（**メタデータ収集中・リターンを一切計算していない時点で確定**）
ファミリー: `CORPORATE_EVENTS`（②支配変化ブランチ。V3有報とはデータ源・頻度が別物）

## 0. 仮説

新規の大量保有報告書（5%超取得の開示）は取得主体の情報・支配意図のシグナルであり、
開示後に正のドリフトが続く（国内外の実証で文書化）。有報の年次「大株主の状況」と違い
**提出日時つき・イベント駆動・約3-6件/営業日**で、CORPORATE_EVENTSの標本供給問題への回答。

## 1. データ（確定）

- `data/jp_large_holdings/`（docTypeCode 350 メタデータ・2021-09〜・縦覧5年ローリング）
- **新規のみ**: docDescription が「大量保有報告書」で始まる行（「変更報告書」は除外。
  買増し/売却の方向がメタデータから判別できないため）。withdrawalStatus=取下げは除外
- 銘柄解決: secCode 優先、無ければ EDINET コードリストで issuerEdinetCode→証券コード
- PIT: submitDateTime の**翌営業日寄り**でエントリー（提出時刻に依らず保守側）

## 2. 仕様（凍結）

- エントリー: 翌営業日寄成 / エグジット: **20営業日後引け**（取引所カレンダー連続性必須）
- 適格: 前日売買代金 ≥ **¥1億**（V4踏襲）・価格データ実在
- 重複: 同一銘柄の後続イベントは先行イベントの保有期間中なら捨てる（先着のみ）
- コスト: 往復 **40bps**
- ベンチマーク: **同期間の等加重市場リターンに対する超過**（素のリターンでの判定禁止＝
  CRASH_DIPBUYの教訓）

## 3. 窓と判定（実測を見る前に確定）

- 選択窓: イベント **2021-09-01〜2024-12-31** / 確認窓: **2025-01-01〜2026-06-30**
  （選択窓で全基準通過時のみ1回開封）
- 基準（選択窓）: ①採用 n ≥ 100 ②40bps後の**超過**中央値 > 0 ③最大案件利益シェア < 20%
  ④上位5%案件の利益シェア < 40%。確認窓は同基準で n ≥ 40
- 併記（判定外）: ES(5%)・勝率・保有期間中の最大同時建玉数・¥20M運用時の実装可能性

## 4. 禁止事項

- 結果後の保有期間（20日）・フロア・重複規則の変更
- 提出者名によるアクティビスト選別（事後選別。やるなら名簿を先に凍結して新窓で別登録）
- 変更報告書の事後追加。素のリターンでの判定
