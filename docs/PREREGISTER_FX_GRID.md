# 事前登録 — FX 複数通貨 L/S グリッド（トラリピ型）＋機構診断

作成: 2026-08-08（**リターン計算前に確定**）
ファミリー: `FX_BASKET`（グリッドは新セル）

## 0. 数理の事前固定（判定の枠組み）

二方向グリッドの連続極限はアンカーA・傾きkの線形平均回帰ポジション p=−k(P−A) と等価で、
その損益は恒等的に

  PnL_gross = (k/2)·[実現分散] − (k/2)·[(P_T−A)² − (P_0−A)²]

＝**「実現分散を収穫し、終端乖離の二乗を支払う」**。価格がマルチンゲールなら両項の期待値は
一致し **E[PnL_gross]=0**（間隔・キャップ・通貨数は分布を変えるが期待値を作らない）。
グロスの源泉は**グリッド間隔スケールの平均回帰プレミアム（分散比 VR<1）のみ**であり、
それにスワップキャリー（在庫の符号次第で正負）が乗り、スプレッドが引かれる。

したがって判定は2本立て:
- **診断D（機構）**: 7ペアの VR(q)。1h基準 q=24(1日)/120(1週)/480(1月)、1d基準 q=5/20。
  VR≥1 が支配的なら「収穫すべき平均回帰が存在しない」＝パラメタ調整では救えない。
- **シミュレーションS（実弾形）**: 下記凍結仕様のトラリピ型を実測bid/ask＋スワップで判定。

## 1. 凍結仕様（S・主仕様）

- ペア: 手元7ペア（EUR/GBP/AUD/NZD_USD・USD/JPY/CHF/CAD）の等ノーショナル・ポートフォリオ
  （全ペア同時＝「複数通貨にわたるL/Sグリッド」。USD建玉は両方向に発生し自然にL/S）
- アンカー: **各暦年の初値**（年次リセンター・PIT）
- 間隔 Δ: **前年の日次レンジ(高値−安値)中央値 × 0.5**（年次固定・PIT）
- 形: 二方向対称。ポジション = clip(−floor((P−A)/Δ), −10, +10) 単位
- 1単位 = 資本C/(7ペア×10段)＝フル在庫で総建玉≈1×C（レバ1倍相当）
- 約定: 分足**高値/安値タッチ**で水準価格の指値約定（OHLC単調3レグパス: 陽線O→L→H→C・
  陰線O→H→L→C）。コスト = 約定バーの実測ハーフスプレッド（p99 winsorize=データ異常のみ除去）。
  ※終値クロス検出は「逆行継続に条件付け」る悲観バイアス（自己検証で−2.7SE）と判明したため
  実データ実行前に修正した。修正後の計測器は連続経路マルチンゲールで期待値0を確認済み
  （振動パス=Δ×回数・トレンド在庫損・バー内往復・E[PnL]=0 の4項self-test）。
- スワップ: 在庫に日次課金/付与（`trading/fx/swap.py`・3Mインターバンク・passthrough 1.0・
  haircut 0 = **ブローカー最良側**。この甘い設定で死ねば頑健に死んでいる）
- 評価: 日次エクイティ（USD換算）→ 全暦日Sharpe

## 2. 感度分析（事前列挙・主仕様昇格禁止）

a) Δ=1.0×レンジ中央値　b) キャリー整合片側グリッド（金利差プラス側の在庫のみ蓄積・
月次で方向再固定）　c) コスト半減（GMO原則固定相当）

## 3. 窓と判定（実測を見る前に確定）

- 選択窓 **2012-2019**（Δに前年が要るため2012開始）/ 確認窓 **2020-2026**（通過時のみ1回開封）
- 基準: ①全暦日 net Sharpe ≥ 1.0 ②負の年 ≤ 1/3 ③上位5日利益シェア < 20%
  ④上位10日除去後 Sharpe ≥ 0.5
- 併記（判定外・リスク実態）: 最大在庫日数・ES(5%)・最大DD・下位5日損失シェア
- 診断DはGO/NO-GOに使わない（機構の説明・「パラメタで救えるか」の判定のみ）

## 4. 事前の見立て（記録のため明記・判定には使わない）

既存13仮説の実測（週次リバーサル負・強弱AR(1)≈0〜負の微小・時間帯効果なし）から
VR≈1が予想され、その場合グロス≈0でスワップ−スプレッドの綱引きだけが残る。
また「多数の小さい実現益＋トレンド時の巨大在庫損」は集中基準③④が正しく罰する形。

## 5. 禁止事項

結果後の Δ・キャップ・アンカー規則・ペア集合の変更。感度セルの主仕様昇格。
不合格後の変種再試行（グリッド族はこの1回で決着）。
