# 事前登録 — 暴落ディップバイ（CRASH_DIPBUY）

作成: 2026-08-02（**戦略リターンを一切見ていない時点で確定**）
ファミリー: `CRASH_DIPBUY`（新規。CORPORATE_EVENTS が V1/V2/V3 全滅で空いた枠に入れる）

## 0. なぜこの設計なのか（過去の壁を回避する構造）

直近4例（売り制約解除・フローα・`xt_alert_flag`・気配不要ML）は**すべて同じ壁**で死んだ:
**αはショート側にあり、その大半〜全部が借りられない銘柄に宿る**。
本仮説は**ロングオンリー**なので、この壁を構造的に回避する。

さらに追い風の実測が既にある:
- 高IVレジームで `ensemble_core` は確認窓でも優位（Q5 44bps/Sh4.35）
- ボラターゲットは逆効果＝**ボラ高が稼ぎ時**（Sharpe 1.43→1.28）

弱点も既知: 低頻度・ロングオンリーゆえ**市場βで見かけが良くなる**。
したがって**主評価は市場超過リターン**とし、素のリターンでは判定しない。

## 1. データとPIT

| 用途 | データ | PIT |
|---|---|---|
| 暴落トリガ | パネル等加重の終値→終値（D日） | D日引け後に確定 |
| 米国夜間 | `dow_night`（NYダウ先物・OSE夜間、schema v8） | D+1朝06:00に確定＝寄付き前 |
| ボラ状態 | `nkvi`（日経VI先物） | D日引け後 |
| 需給 | 売買内訳フロー・信用残・空売り残高・増担保（既存4系統） | 各系統の保守側ラグ済み |
| 価格 | `daily_adj_*` の未調整O/C（2026-08-01に全年95-97%へ補完済み） | — |

**KOSPI・中国は当日値を使わない**。KOSPIは09:00 KST＝東京と同時、中国は10:30 JST開場で、
**東京の寄付き時点では当日値が存在しない**（使えば確実にルックアヘッド）。
Stooqが現在ブロック中で履歴も未取得のため、本仕様では**前日値としても使わない**。
取得できたら別事前登録で「前日KOSPI/中国」を追加検証する。

## 2. トリガ（確定）

D日の等加重市場リターン（終値→終値）が **≤ −3.0%** の日を暴落日とする。
2018-2026で132日、全年8〜20日と分布し単一エピソード依存にならないことを
**特徴量のみで確認済み**（リターン不参照）。

- 連続する暴落日は**同一エピソードとしてまとめない**（各日を独立に建てる。
  ただし同時建玉上限で自然に抑制される）。
- 感度分析は **−4% / −5%** の2水準のみ。それ以外の閾値は試さない。

## 3. 執行（確定・気配不要）

- **エントリ: D+1営業日の寄成**（D日引けまでの情報のみで発注＝寄前気配不要）
- **エグジット: エントリから H 営業日後の引成**
- **H = 10 を主仕様**、H = 5 / 20 を感度分析
- コスト **往復20bps**（板寄せ実測1.5+0.5bpsに対し十分保守側）
- **ロングオンリー・レバなし**（元本¥20M・信用倍率1.0）。100株整数単元
- 1銘柄あたり上限 = 元本 / N。**N = 20 を主仕様**、10 / 40 を感度分析
- 1単元が予算を超える銘柄は建てない（薄く広くではなく買える範囲で等金額）

## 4. 銘柄選択（確定・すべてD日引けまでの情報）

母集団: 個別株・前日売買代金 ≥ ¥10億（既存の本番ユニバース）。

スコアは次の5項目の**断面zの単純平均**（重みは付けない＝最適化しない）:

| 項目 | 向き | 理由 |
|---|---|---|
| `fall_5d` = 直近5営業日の自身のリターン | **負ほど高スコア** | 売られすぎを拾う |
| `spike_1d` = D日当日の自身のリターン | **負ほど高スコア** | 短期スパイク（投げのクライマックス） |
| `xt_ssr_to_so` = 大口空売り残高の発行済比 | 高いほど高スコア | 踏み上げ余地 |
| `flow_close_z` = 信用返済の方向 | 低い（投げ）ほど高スコア | 投げ売りの反動 |
| `equity_ratio` = 自己資本比率 | 高いほど高スコア | 暴落時の信用不安を避ける |

欠損は断面z化後に0で埋める（＝その日の平均的な銘柄）。
**中核である `fall_5d` が欠けた行は除外**（疎特徴量の罠を回避）。

## 4A. 利確・損切り（確定）

保有中は日足で監視し、**銘柄ごとのボラティリティでスケール**した水準に置く
（固定%だと低ボラ銘柄で過敏・高ボラ銘柄で無効になるため）。
σ は PIT安全な `ivol`（shift=1）を用い、保有期間 H にスケールする: `σ_H = ivol × √H`。

- **利確 TP = +2.0 σ_H**
- **損切り SL = −1.5 σ_H**
- どちらも触れなければ H 日後の引成で手仕舞い

**約定の保守ルール（重要）**: 日足では高値と安値のどちらが先に付いたか判別できない。
**同日に TP と SL の両方が日中レンジに入った場合は SL が先に約定したものとみなす。**
（AGENTS「ブリーチ足終値約定は実装不能な好条件」の轍を踏まないため。）
TP/SL の約定価格はその水準ちょうどとし、ギャップで飛び越えた場合は**その日の始値**で約定とする。

価格経路の判定は**調整済み価格**（分割安全）で行う。**未調整価格は単元数の決定にのみ使う**
（調整済価格は建値でない）。

TP/SL 無しの版も併記するが、**主仕様は TP/SL あり**。倍率(2.0 / 1.5)は結果を見て変更しない。

## 4B. 執行価格の感度（VWAP）

主仕様のエントリは寄成。加えて **VWAP エントリ**を感度分析として1本だけ見る。
VWAP は近似ではなく **`売買代金 ÷ 出来高` の実値**を使う。
（寄成は板寄せで最も安いが、暴落翌朝は寄付きが荒れるため、日中平均での取得可能性を確認する。）

## 5. 米国夜間による条件付け（1つだけ）

主仕様は**無条件**。クロスマーケットの変種は**1本だけ**登録する:

- **US-STABILIZED**: `dow_night(D+1) > −1.0%` のときだけ建てる（下げ止まり確認）

これ以外の条件付け（継続方向・閾値違い・VI条件・KOSPI/中国）は本試行では行わない。

## 6. 判定（実測を見る前に確定）

ロングオンリーなので**素のリターンでは判定しない**。
**同期間・同保有日数の等加重市場リターンを引いた超過リターン**で判定する。

主仕様（−3%トリガ・H=10・N=20・無条件）が次を**すべて**満たしたときだけ次段階へ:

1. エピソード数 **≥ 30**
2. 20bps控除後の**エピソード超過リターンの中央値 > 0**
3. **最大利益エピソードの利益シェア < 20%**（1回依存の排除）
4. **超過リターンの平均 > 0** かつ **勝率 ≥ 50%**

副次指標（判定には使わない）: 素のリターン、ES(5%)、最大損失、年別内訳。

- 当日のKOSPI・中国・日中値動きの使用（すべてルックアヘッド）
- 素のリターンやβ込みSharpeを成績として主張すること
