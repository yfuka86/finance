## 1. データとPIT規約

- 正本: `data/jp_ownership/filings.jsonl`（`scripts/collect_edinet_major_shareholders.py`、
  提出日単位・append-only・日次レスポンスのSHA-256を `scanned_dates.jsonl` に記録）。
- **PIT時刻は提出日 `SubDate`**。決算期末 `PerEn`（約3か月前）は公開時刻ではないので使わない。
- 同一 `(symbol, period_end)` に複数報告がある場合は**最後に提出されたもの**を採用（訂正報告書）。
- 前年比は `period_end` の差が **300〜450日**の連続年度のみ。年度飛びを1年分の変化と誤認しない。

## 2. シグナル（本仕様・確定）

上位10名の各保有者を、名称で**プール型名義（信託口・マスタートラスト・カストディ・
グローバルカストディアン等）**か否かに二分する。プール型は多数の受益者の代理であり
**浮動株**なので固定株から除く（`CUSTODIAN_PATTERNS`、`ownership_features.py`）。

- `fixed_ratio` = 上位10名のうち**非カストディアン**の保有比率合計
- `delta_fixed` = `fixed_ratio(t) − fixed_ratio(t−1)`
- **イベント成立: `delta_fixed ≤ −0.02`**（前年比2%ポイント以上の固定株低下）

閾値2ppの根拠（**特徴量のみで確認・リターン不参照**）: 全期間2016-2026（n=35,970）で
`delta_fixed` は平均 **−0.39pp/年**・中央値 0.00pp・`≤−0.02` が全体の **20.2%**。
年別平均は2017〜2025が**全年マイナス**で、銘柄内の持合い解消ドリフトは実在する。
1pp級は10位近辺の順位入替ノイズと分離できないため、経済的に有意かつノイズを
上回る水準として2ppを事前固定する。

注: 断面平均 `fixed_ratio` は2016年0.431→2023年0.454と**上昇**するが、これは
創業者保有の高い新規上場銘柄の流入によるもので、銘柄内YoYの低下と矛盾しない。
本仕様が使うのは断面水準ではなく**銘柄内YoY差分**である。

方向は既存の事前登録（資本解放＝ロング）に従い**ロングのみ**。結果を見て反転させない。

## 4. モデルと窓（凍結）

- Ridge(alpha=10.0) + median impute + standardize（V1と同一パイプライン）
- 特徴量（確定・追加変更禁止）:
  `delta_fixed, fixed_ratio, custodian_ratio, delta_top1,
   book_to_price, earnings_yield, op_margin, equity_ratio, cash_assets, roe`
- 財務量は提出日**より前**に開示済みの直近決算のみを `merge_asof` で結合する
- 学習: `exit_date < 2024-01-01` / **OOS: `event_date ≥ 2024-01-01`**
- 選択規則: `prediction > 0` かつ同時建玉10件未満

## 5. 合否基準（V1と同一・事前確定）

低頻度なので日次Sharpeでは判定しない。**次の3つを全て満たしたときのみ次段階へ進む**:

1. OOS採用案件数 **≥ 20**
2. 20bps控除後の**案件中央値 > 0**
3. **最大利益案件の利益シェア < 20%**（1案件依存の排除）

副次指標として平均・勝率・ES(5%)・最大損失を報告するが、合否には使わない。
