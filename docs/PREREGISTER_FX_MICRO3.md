# 事前登録 — FX 残余3セル（週末ギャップ・水曜ロールオーバー・時系列週次リバーサル)

作成: 2026-08-08（**リターン計算前に確定**）。3仮説同時検証＝多重性を明示。
ファミリー: `FX_BASKET`

## H1 週末ギャップ・フェード（毎週×7ペア）

- 機構: 日曜17:00 ET再開時の薄い板がギャップをオーバーシュートし埋めに戻る（未検証の定型）
- ギャップ = 日曜再開初バーmid ÷ 金曜17:00 ET最終バーmid − 1
- **|ギャップ| > 2×再開バーの実測ハーフスプレッド**（適応閾値）かつ ≤3%（データ異常除外）
  の週のみ、再開バーで**逆張り**エントリー → 月曜12:00 ETの最終バーで手仕舞い
  （ロールオーバー非跨ぎ＝スワップなし）。コスト=両端の実測ハーフスプレッド
- ポートフォリオ: 発火ペア等ウェイト（notional 1/7固定）

## H2 水曜トリプルスワップ・ロールオーバー（毎週×適格ペア）

- 機構: 水曜17:00 ETに受渡日が3日跳び、公正スポットは3日分の金利差だけ動くはず。
  調整が不完全ならキャリー正側ロングの1時間保有が残差を取る（帰無仮説=完全調整）
- 適格: 1か月ラグの3Mインターバンク金利差 |diff| ≥ 1%。方向=キャリー正側ロング
- 水曜 16:30 ET 最終バー建て → 17:30 ET 初バー手仕舞い。損益 = 価格リターン + 3日分スワップ
  （`trading/fx/swap.py`・水曜=3日規約）− 両端実測ハーフスプレッド（17:30の広幅は実測どおり課金）
- 診断（判定外）: 月火木の同構成（1日スワップ）を対照として記録

## H3 時系列・週次リバーサル（VR実測の直接収穫・毎週×7ペア）

- 根拠: グリッド検証のVR診断（選択窓）で 1d→1w 0.966 / 1d→1m 0.886、
  AUD/NZD/CAD は0.80-0.86 ＝ペア内時系列の負の自己相関が実在。既往の「週次リバーサル」
  棄却は**横断面**（通貨ランク）であり時系列は未検証
- 毎週月曜 08:00 London の初バーで: 前週比リターンの z（52週ローリングσ・最低40週）
  が |z|≥1 なら **−sign(z)** を1週間保有（次週月曜に再評価・切替時のみ両端コスト）
- スワップ: 保有週に日次計上（swap.py・曜日規約）。ポートフォリオ: 7ペア等ウェイト

## 窓と判定（3セル共通・実測を見る前に確定）

- 選択窓 **2011-2019**（H3は52週ウォームアップで実効2012-）/ 確認窓 **2020-2026**
  （セルごとに全基準通過時のみ1回開封）
- 基準: ①全暦日 net Sharpe ≥ 1.0 ②負の年 ≤ 1/3 ③上位5日利益シェア < 20%
  ④上位10日除去後 Sharpe ≥ 0.5
- 禁止: 結果後の閾値（2×spread・|z|≥1・|diff|≥1%）・時刻・保有期間の変更。
  セル間の事後合成。診断（H2対照）の戦略昇格。
