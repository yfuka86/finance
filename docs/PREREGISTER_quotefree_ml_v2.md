## 凍結する構成（これ以降いっさい変更しない）

| 項目 | 値 |
|---|---|
| モデル | `Ridge(alpha=30.0)` 年次ウォークフォワード（`<Y` で学習 → `Y` を予測） |
| 特徴量 | `BASE_FEATURES − TODAY_OPEN_COLS` ＋ `FLOW_FEATURES` ＋ `prev_value` ＋ `EXTRA_FEATURES` |
| 欠損処理 | **中核**(BASE/FLOW/prev_value)が欠けた行は除外。`EXTRA_FEATURES` のみ学習平均で0埋め |
| 標準化 | 学習期間の平均・標準偏差のみ使用（テスト期間の統計は使わない） |
| スコア | 日次でクロスセクション・デミーン |
| 構築 | `magnitude` ／ 8銘柄per side |
| サイズ | 元本 ¥20M・信用2.0倍 |
| ユニバース | 個別株・前日売買代金 ≥¥10億・貸借銘柄のみ・規制銘柄ショート除外 |
| 執行 | 寄成 → 引成（**気配不要**。前日確定データのみで発注） |
| コスト | 1.0bps/side を主判定、2.0bps/side を併記 |

## 合格基準（実測を見る前に確定）

**1.0bps/side で net Sharpe ≥ 1.0**（v1 と同一の基準。緩めない）。

## 期待値の見積り（テストではない）

v1 は選択窓 1.30 → 確認窓 0.87（**−33%**）だった。v2 に同じ劣化率を当てると
**1.43 × 0.67 ≒ 0.96** で、**基準1.0をわずかに下回る**見込み。
つまり v2 は「有望だが、たぶん届かない」。これは推定であって判定ではない。

## 棄却したDD対策（選択窓で設計・いずれも不採用）

| 案 | 結果 | 判定 |

| ボラターゲット（目標15-40%・前日までの実現ボラでレバ調整） | Sharpe 1.43→1.28、Calmar 1.29→1.06-1.18 | **逆効果**。AGENTS の「ボラ高＝稼ぎ時」がここでも成立 |

## 評価の手順（新窓が貯まってから1回だけ）

1. 新規期間の日次データを収集（`collect_jp_daily_history.py` / `collect_jp_margin_flows.py`）
2. 上表の構成を**一字一句変えずに**再学習・再予測し、`2026-08-01` 以降のみで集計
3. 1.0bps/side の net Sharpe を基準1.0と比較して GO / NO-GO
4. **未達なら棄却。再調整して再測定してはいけない**（その時点で新窓も消費される）

必要期間の目安: Sharpe の標準誤差 ≈ √(1/N年)。**最低6ヶ月、できれば12ヶ月**。

## 注意（この構成を触る人へ）

- 疎な特徴量を足すとき `dropna` を緩めてはいけない。中核特徴量が欠けた行を混ぜると
  流動性境界の断続銘柄が入り、同一構成が Sh1.30 → −0.04 / DD−81.5% に激変する（実際に踏んだ）。
- `vol20` は PIT 違反（当日終値を含む）。特徴量に足さないこと。予測用のボラは `ivol`。
- `xt_alert_flag` は単体IC t=−13.46 と極端に強いが、αが規制銘柄＝ショート禁止側にあるため
  本番制約下ではほぼ効かない。単体ICの強さで特徴量を選ばないこと。
