## 期待値の見積り（テストではない）

v1 は選択窓 1.30 → 確認窓 0.87（**−33%**）だった。v2 に同じ劣化率を当てると

つまり v2 は「有望だが、たぶん届かない」。これは推定であって判定ではない。

## 評価の手順（新窓が貯まってから1回だけ）

1. 新規期間の日次データを収集（`collect_jp_daily_history.py` / `collect_jp_margin_flows.py`）
2. 上表の構成を**一字一句変えずに**再学習・再予測し、`2026-08-01` 以降のみで集計
3. 1.0bps/side の net Sharpe を基準1.0と比較して GO / NO-GO
4. **未達なら棄却。再調整して再測定してはいけない**（その時点で新窓も消費される）

必要期間の目安: Sharpe の標準誤差 ≈ √(1/N年)。**最低6ヶ月、できれば12ヶ月**。

## ★2026-08-02 再現検証の結果 — 上表の 1.43 は再現できない

`scripts/verify_quotefree_ml_v2.py`（本節の数字はこれで再生成できる）。

**前提の健全性は先に確認済み**: `scripts/verify_baseline.py` が **4/4 PASS**
（リサーチ@3bps 5.326 / @7bps 3.425 / 単元全期間 1.775 / 単元OOS24+ 3.433、
いずれも期待値との乖離 0.1〜2.0%）。パネルと単元BTの機構はこの環境で正しく動く。

その上で、凍結仕様を committed code から組み直し、事前登録が曖昧に残していた軸を
**24構成すべて**掃いた（target×構築×銘柄数×レバ）。結果:

| 構成 | Sharpe | 年率 | DD |
|---|---:|---:|---:|
| demeaned / magnitude / 8per side / **1.0x** | **0.462** | 7.4% | −33.2% |
| demeaned / magnitude / 8per side / 2.0x（本仕様） | 0.429 | 14.3% | −62.0% |
| demeaned / magnitude / 15per side / 2.0x | 0.415 | 10.1% | −49.0% |
| rank / magnitude / 8per side / 2.0x | 0.169 | 5.5% | −61.5% |
| （参考）理想ブック q=0.017 / 0.05 / 0.10 | 3.446 / 3.069 / 2.335 | — | −15.2 / −8.0 / −6.8% |

- **単元BTの最良は 0.462**。記録の 1.43 はどの構成でも出ない。
- IC は 0.0323 / t=10.15 で、記録（0.0275 / 9.16）より**むしろ高い**。
  差はシグナルではなく**ポートフォリオ構築側**にある。
- DD −36.8% という記録の署名は、単元BT（−33〜−62%）と理想ブック（−7〜−15%）の
  どちらのレンジにも整合しない。
- 潰した仮説: パネル流動性フロア(5e8/1e9)、target(demeaned/rank)、スコアのデミーン有無、
  construction(magnitude/magnitude_adaptive/dollar_neutral/risk_parity)、
  単元価格の生値/調整済み（0.429 vs 0.440＝無関係）、銘柄数(8/15/30/50)、レバ(1.0/2.0)、
  理想ブック分位(0.01〜0.20)。

### 帰結: **v2 は選択窓の時点で既に基準未達**

合格基準は 1.0bps/side で net Sharpe ≥ 1.0。再現可能な選択窓の値は **0.43〜0.46**。
**選択窓は構造的に楽観側**（v1 は選択1.30→確認0.87 で −33%）なので、
フォワードでの期待値は 0.96 ではなく **概ね 0.3 前後**。

→ **2027-08-02 まで待つ意味は無い。** 判断は次のいずれか:
1. 再現可能な基準に基づき **v2 を今 NO-GO とする**（推奨）
2. フォワード観測は続けるが、期待値を 0.96 でなく ~0.3 として記録し直す

いずれにせよ、**1.43 を根拠に用いてはいけない**。

## 注意（この構成を触る人へ）

- 疎な特徴量を足すとき `dropna` を緩めてはいけない。中核特徴量が欠けた行を混ぜると
  流動性境界の断続銘柄が入り、同一構成が Sh1.30 → −0.04 / DD−81.5% に激変する（実際に踏んだ）。
- `vol20` は PIT 違反（当日終値を含む）。特徴量に足さないこと。予測用のボラは `ivol`。
- `xt_alert_flag` は単体IC t=−13.46 と極端に強いが、αが規制銘柄＝ショート禁止側にあるため
  本番制約下ではほぼ効かない。単体ICの強さで特徴量を選ばないこと。
