# 事前登録 — 正スワップ通貨の暴落ディップバイ（FX_CARRY_DIP）

作成: 2026-08-04（**リターンを一切見ていない時点で確定**）
ファミリー: `FX_BASKET` の第2仕様

## 0. 着想と、無条件キャリーとの違い

無条件キャリー（第1仕様）は **NO-GO**（選択窓 Sharpe 0.138 / 確認窓 0.069）。
死因ははっきりしていて、**年率+2.3%のスワップを価格変動が食い尽くす**。
DD −22.8% に対して年率 +1.25% では話にならない。

本仕様はその死因を逆手に取る。キャリートレードは暴落で死ぬのだから、
**暴落した後に入れば安く仕込めて、待つ間もスワップが入る**。
＝無条件保有ではなく**条件付きエントリー**であり、シグナルが別物。

## 1. ★窓の状態（重要・先に明示する）

**2011-2025 の全期間は第1仕様（無条件キャリー）で選択窓・確認窓とも消費済み**。
したがって本仕様が基準を満たしても、**それは確認ではなく選択段階の結果**にすぎない。

- 本試行は **選択窓 2011-2019 / 参考窓 2020-2025** として報告する
- **合格しても実弾候補にはしない**。判定には**新しい未使用期間（2026年以降のフォワード）**が要る
- この扱いを結果を見た後に変更しない

## 2. データ

第1仕様と同じ。Dukascopy 日足 bid/ask（7 USDペア・2011-2025・欠損ゼロ・実測スプレッド）、
FRED 3か月インターバンク金利、`trading/fx/swap.py`（水曜3日・土日0・週合計7日）。

## 3. 仕様（確定）

各 USD ペアを**正キャリーになる向き**に固定する（金利の高い通貨をロング）。
向きは毎日の金利差で決まり、金利が逆転すれば向きも入れ替わる。

- **キャリー条件**: その向きでの金利差 **> 0**（閾値は置かない）
- **暴落条件**: その向きでの**直近5営業日リターンの z ≤ −2.0**
  （z は同じ向きの過去60営業日リターンの標準偏差で正規化。通貨ごとのボラ差を吸収するため、
  ペア個別の%閾値は使わない）
- **エントリ**: 条件成立日の**翌営業日の始値**（ask で買う）
- **保有**: **20営業日**。途中で手仕舞わない（利確・損切りなし）
- **建玉**: 条件を満たすペアに**等金額**。同時に最大4ペア。総エクスポージャは元本比1.0を上限
- **スワップを加算**（曜日規約つき）。コストは**実測スプレッド**（往復）

利確・損切りを置かないのは、このリポジトリで**5例連続でTP/SLが有害**だったため
（暴落ディップバイでは超過 −0.26%(あり) vs +0.03%(なし)）。

## 4. 判定（実測を見る前に確定）

Sharpe は**全暦日ベース**（建玉が無い日は0）。稼働日だけで年率化しない。

1. コスト・スワップ込みの **net Sharpe ≥ 1.0**
2. 負の年が全年数の **1/3 以下**
3. **上位5トレードの利益シェア < 20%**
4. **上位10トレードを除いても Sharpe ≥ 0.5**

3・4 は決算戦略で入れ忘れて後から落とした基準。最初から入れる。
