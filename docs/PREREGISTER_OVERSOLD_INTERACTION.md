## 1. ルールセル（凍結・15本）

- ユニバース: ¥10億パネル・**ロングオンリー現物**・すべて板寄せ
- 銘柄条件: D時点の**5日リターン断面z 下位10%**（売られすぎ）
- 市場条件: TOPIX 5日リターンが A0: ≤0% / A1: ≤−2% / A2: ≤−4%（頻度3段階）
- エントリー: D+1寄成。保有: h1=D+1引け / h3=D+3引け / h5=D+5引け
- **TP（h3/h5のみ）**: 累積リターン（終値評価）≥ **+2×ivol20** で**翌営業日寄成退出**
  （ブリーチ足内約定は禁止＝実装可能形のみ）
- コスト: 寄1.5bps＋引0.5bps（TP退出は寄1.5bps）
- ポートフォリオ: 全ライブ建玉の等ウェイト・日次リバランス

## 2. MLセル（凍結・2本）

- 特徴量8本（PIT・D時点）: z5日・z1日・z(ivol20)・RSI14 ＋ 市場M(5日) ＋ 交互作用
  z5×M・z1×M・RSI×M
- ターゲット: D+1寄→D+3引の断面デミーンリターン・年次WF
- M1: Ridge(α=30) / M2: **MLP(32,16)**（sklearn・early stopping・学習行40万サブサンプル
  random_state=0固定＝「deep系」の最小誠実形）
- 建玉: 予測上位10%ロング・h3・3トランシェ重畳・TPなし
